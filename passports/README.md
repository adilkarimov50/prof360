# Криминологический паспорт населённого пункта

Цифровое издание криминологических паспортов **9 населённых пунктов** Алматинской области
и г. Алматы за 2026 год.

**Издание:** https://adilkarimov50.github.io/krim-passport/

Паспорта опубликованы в виде интерактивной презентации: структура преступности в сравнении
с аналогичным периодом прошлого года, портреты правонарушителя и потерпевшего, распределение
по времени суток, точки концентрации на карте, административная практика по форме 1-АД,
криминогенные факторы, лица профилактического учёта и приоритетные мероприятия с указанием
объекта, исполнителя, срока и критерия оценки.

## Структура репозитория

```
data/          структурированные паспорта в JSON и геоданные объектов
docs/          сайт цифрового издания (источник GitHub Pages)
scripts/       оцифровка документов, сборка данных, QR-код, Word-версия
build/         локальные результаты сборки, в репозиторий не попадают
```

## Как добавить новый населённый пункт

Паспорта построены по единому шаблону из 18 разделов и 16 таблиц, поэтому добавление
нового населённого пункта не требует изменения кода.

1. Оцифровать документ:

   ```bash
   python scripts/digitize.py "Крим паспорт Узынагаш.docx" --id uzynagash
   ```

2. Добавить координаты ключевых объектов в `data/geo.json` под тем же идентификатором
   (точки концентрации, проблемные улицы, криминогенные объекты, населённые пункты округа).
   Объекты, у которых в паспорте нет адреса, вносятся в раздел `unlocated`.

3. Пересобрать данные сайта:

   ```bash
   python scripts/build.py
   ```

Новый паспорт появится в переключателе на всех страницах автоматически.

## Сборка остальных артефактов

```bash
# QR-код на издание (SVG для сайта, PNG для документов)
python scripts/make_qr.py

# Word-версия паспорта с блоком «Цифровая версия» и QR-кодом
python scripts/make_docx.py "Крим паспорт Каскелен.docx" --id kaskelen
```

Исходные документы не изменяются: результат сохраняется в каталог `build/`.

## Предпросмотр сайта

Страницы работают и без веб-сервера — данные встроены в `docs/assets/js/data.js`.
Для проверки в условиях, близких к публикации:

```bash
python -m http.server 8777 --directory docs
```

## Источники данных

Сведения взяты из криминологических паспортов за 2026 год (формы 1-М, 1-АД, данные акимата,
центра занятости населения, отдела образования и районной больницы). Координаты объектов
получены геокодированием названий по [OpenStreetMap](https://www.openstreetmap.org/copyright)
и носят ориентировочный характер; точность привязки указана для каждого объекта
в `data/geo.json`.
